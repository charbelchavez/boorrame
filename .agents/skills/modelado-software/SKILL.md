# Modelado de software

Guía la creación de modelos legibles y adecuados al alcance actual del análisis.

- Antes de dibujar, aclara qué pregunta debe responder el modelo y quién lo usará.
- Elige el tipo de modelo más sencillo que responda esa pregunta; explica brevemente por qué es apropiado y qué queda fuera.
- Mantén coherencia con requisitos y vocabulario existentes. Marca supuestos y elementos no confirmados.
- Acompaña cada diagrama con una descripción, una leyenda si hace falta y límites conocidos. Para Mermaid, produce sintaxis válida y fácil de editar.
- Revisa que los nombres sean consistentes, las relaciones tengan sentido y el nivel de detalle no implique decisiones prematuras de implementación.
- Explica conceptos y notación conforme aparecen; invita a la persona a revisar el modelo y razonar sobre sus partes.
- Organiza modelos en `docs/04-modelado` y registra decisiones importantes en `docs/06-glosario-y-decisiones`.
